## Unavailable assets and services

| What | Why | Effect on the edit |
|---|---|---|
| **Stock footage**: Pexels, Pixabay, Mixkit, Videvo, Wikimedia Commons, Internet Archive | This environment's network policy denies CONNECT to those hosts (proxy 403/`connect_rejected`) | No real stock B-roll. All B-roll is motion graphics plus the speaker plate. |
| **Licensed music / SFX libraries**: Freesound, Mixkit audio | Same network policy | Music and SFX were synthesised instead. |
| **AI video generation**: Figma Weave, Kling | "Video models are only available on paid plans" (Figma starter plan) | Not used. |
| **AI image generation**: Figma Weave, Nano Banana Pro | Both images were generated (22 Weave credits, with your approval), but their host `media.weavy.ai` is blocked here, Figma's plugin sandbox has no `fetch`, and Figma's export host `www.figma.com` is blocked too | The images could not be downloaded, so they are **not in the edit**. No Figma AI credits were spent on the planned regeneration, because the export test failed first. |
| Hugging Face (Whisper / faster-whisper weights) | Network policy | Transcription used the same model families via sherpa-onnx GitHub release assets, run offline. |

## Tools

FFmpeg 6.1.1 (libx264, AAC, `sidechaincompress`, `alimiter`) · Python 3.13 + NumPy + Pillow · sherpa-onnx 1.13.8 with Whisper large-v3-turbo (int8) and NVIDIA Parakeet-TDT 0.6B v2 (int8), from `github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models`.
