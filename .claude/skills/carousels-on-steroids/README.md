# Carousels on Steroids · free Claude Code skill

Instagram carousels where every slide is a looping motion-graphics video **and** the whole post is one
continuous scene: smoke, embers, ingredients and the product itself cross the edges as you swipe.

- Interviews you first: your business, topic (or it finds one), goal, $0 or AI assets, your images, your style.
- Builds one self-contained HTML file: strip preview, swipe preview, record mode, one-click export.
- Checks every slide itself (contact sheets, loop seams, slide edges) and renders frame-exact MP4s.
- $0 by default. Optional AI product shots via Higgsfield (always shows the cost and asks first).

Example inside: `examples/ember-and-bun/` (a smash-burger launch, "The Inferno"), with the prompt that made it.

Companion kit: **Carousel-Kit.zip** (static style-sheet carousels: 6 style sheets, your own photos, your own
style-sheet image, optional mascot). One install prompt handles both and asks which kind you want.

Install: paste the install prompt into Claude Code (see INSTALL-PROMPT.md).
Needs: Google Chrome, Node.js 22+, Python 3, ffmpeg (all free; Claude installs what's missing).
Fonts: Anton, Anybody, JetBrains Mono, SIL Open Font License (see engine/fonts/).
